How hib works

One workload, one disruption, from hib run to hib restore. Press Next or the arrow keys.

Commands that stay running as the Supervisor

One Supervisor per workload. It is the parent of train.py and listens on its socket.

  • hib run train.py
  • hib restore <location>

Commands that send one message and exit

They talk to a running Supervisor through its socket. They start no processes.

  • hib checkpoint --workload train
  • hib status --workload train
