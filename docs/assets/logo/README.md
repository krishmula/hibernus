# Hibernus logo

| File | Use |
|---|---|
| `hibernus-logo-light.svg` / `.png` | Mark and wordmark, for light backgrounds |
| `hibernus-logo-dark.svg` / `.png` | Mark and wordmark, for dark backgrounds |
| `hibernus-mark.svg`, `hibernus-mark-512.png` | The sleeping bear alone |
| `hibernus-icon.svg`, `hibernus-icon-512.png` | Bear head only, for favicons, avatars and sizes under 32 px |
| `hibernus-social-preview.png` | 1280 × 640 image for the repository's social preview |

- Bear color: `#D9792B`. Wordmark: `#1B1F27` on light, `#F2EDE6` on dark. The wordmark is Inter SemiBold, converted to outlines.
- The mark's background is transparent, so it works on either background.
